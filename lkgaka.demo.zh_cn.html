Ikagaka 默认 Ghost nar

使用方法

基本上与 SSP 相同。

  • 将 nar 拖放到 Ghost 上进行安装
  • 通过右键菜单进行各种操作
  • 可以保存状态。请通过“结束基础软件”或“全部结束”等方式结束基础软件后，再关闭浏览器。（如果清除缓存等，根据设置，保存的状态可能会被删除。）

支持情况

浏览器
IE11+、Fx、Chrome（含 Android 版）、Mobile Safari（iOS 8 以后版本）
规格
  • 樱花脚本
  • SHIORI/3.1 事件
Ghost
  • 启动时不加载 SAORI 的华和梨
  • 里々
  • 启动时不加载 SAORI 的 YAYA
  • 启动时不加载 SAORI 的文5
  • 启动时不加载 SAORI 的华和梨7
  • 仅包含标准插件的 MiyoJS
SHIORI（栞）的限制事项

加载 SAORI 时就会崩溃。将来计划实现，但优先级较低。

里々
由于已将 satori_conf.txt 的 @SAORI 改写为忽略 SAORI 进行加载的处理，因此与 SAORI 相关的操作可能会引发各种问题。
由于包含了相当于 ssu.dll 的功能，如果只使用 ssu.dll，则可以照常运行。
华和梨7
由于使用旧通信协议 SHIORI/2.6 进行通信，可能更容易出现 bug。
基础软件功能实现情况

大致情况

  • 首次启动、启动、切换、呼叫、结束、全部结束；具备类似 SSP 的回退处理（例如没有 OnFirstBoot 时调用 OnBoot 等）
  • 启动时信息类尽可能遵循 SSP，但 Ghost 路径、字体等被省略
  • 支持的樱花脚本为 SakuraScriptPlayer.js
  • Communicate 尚未经过充分测试，但姑且具备功能。可能无法运行。
  • 换装功能尚未完成。
  • 没有 Ghost 缓存。

在自己的网站上使用

虽然部分 Ghost 可以运行，但由于状态不完整，之前并未主要发布；如果您觉得当前运行状态也可以，请使用。

已在 Ikagaka.demo (Github) 发布，请按照 readme.txt 操作。

请求运行报告

GitHub 用户：Issues

非 GitHub 用户・简单启动报告等：如何か开发讨论帖

请报告 ○○ 已启动/运行、虽然运行但似乎因未知原因而异常、以及其他注意到的事项等。

如果可以，请尽量使用 IE、Fx、Chrome 等的开发者工具，在一定程度上确定 bug 的原因。

  • 在上述限制下运行。
  • 樱花脚本有很多尚未支持，但如果看似已支持的脚本出现 bug，请报告。
  • Shell 相关也可能出现加载时错误或运行时错误。部分功能尚未实现。也请报告这些情况。
  • 可以多重启动，但目前各 Ghost 是单独运行、彼此之间没有相互管理的模拟状态。关于此事的 bug 报告请暂缓。
  • 与“dlopen”相关的错误是 SAORI 引起的，因此无需报告。
  • bug 报告不一定马上处理。因为很忙且要做的事情堆积如山，根据情况可能会长期搁置。
